Feed & connectivity

SSE Live— event stream over the dev proxy; jobs update without a reload.
Polling— stream unavailable, falling back to 1 Hz GET /jobs. Still updating.
Disconnected— the feed gave up. Progress will not update until it reconnects.

The three states are distinct on purpose: “polling” is degraded-but-working, “disconnected” is terminal. One label for both would read as a lie.

Failure surfaces

401 — the API key is missing or wrong. One banner at the top of the page, with a Retry that re-checks and refetches.
Course delete — the last remaining course cannot be deleted from the UI: with no course selected there is no path to create the next one. The command refuses rather than stranding you.
Render failure — any page that throws shows a panel naming the page and offering Retry; the navbar and job drawer stay mounted so you can still see what happened.
Nothing here yet — empty states say what to do next, never a blank rectangle.
